# 2026-04-29：副本 NPC 受伤修复 + NPC HP 系统

## 修改内容

### 问题
1. 玩家攻击副本中的怪物（NPC），怪物不掉血
2. NPC 没有 HP 和受伤逻辑
3. `OnHandleSkillCast` 的目标查找只查玩家字典（`actors_`），找不到 NPC

### 修复

**1. `include/aegis/game/npc_actor.h`**
- 新增 `TakeDamage(int32_t damage)` 方法
- 新增 `IsDead()`, `GetHp()` 方法
- 新增 `DefaultMaxHp = 50` 常量
- 新增 `hp_` 和 `is_dead_` 成员变量

**2. `src/game/npc_actor.cpp`**
- 实现 `TakeDamage()`：扣血逻辑，血量归零时标记死亡

**3. `src/game/scene_actor.cpp` — `OnHandleSkillCast()`**
- 目标查找改为同时支持 PlayerActor 和 NpcActor
- 伤害计算和 `SCDamageNtf` 构造适配两种目标类型
- 坐标读取适配 NPC

### 验证方式
- 编译通过
- 启动服务端 + 客户端，进入副本
- 玩家自动攻击怪物 → 怪物血条应该变化，最终死亡
